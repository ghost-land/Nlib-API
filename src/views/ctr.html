📁 Categories

GET /ctr/category/:category

List all Title IDs in a specific category. Use extras to include every nested extras subfolder.

Parameters

  • category path required - Category name. Top-level: base, digital-demos, kiosk-demos, region-free, unknown-other, dlc, dsiware, extras, updates, videos, virtual-console, themes. Nested extras: extras/hb, extras/rom-hacks, extras/devapps-misc, extras/custom-dsiware, extras/translated-games

Example Requests

GET /ctr/category/base
GET /ctr/category/kiosk-demos
GET /ctr/category/extras
GET /ctr/category/extras/hb

Response

{
  "category": "base",
  "count": 5339,
  "titles": [
    "0004000000030000",
    "0004000000030100",
    "0004000000030200"
  ]
}

🔗 Title Catalog

GET /ctr/catalog/:kind/:platformSerial

Title family from 3dsdb title_catalog.json: same game across regions, with linked update / DLC / demos / extras. Id form is kind/platform:serial (e.g. game/CTR:KPF).

GET /ctr/catalog/dsiware/TWL:KVM

🎮 Game Data

GET /ctr/:tid

Get detailed information about a title by its Title ID, including all available media URLs and catalog related tree (regions / update / DLC / demos).

Parameters

  • tid path required - 16-character hexadecimal Title ID
  • fields query optional - Comma-separated list of fields to include in response. Example: name,description,publisher,region,category,related
  • related query optional - Set to 0 / false to omit the catalog related tree

Example Requests

# Full response
GET /ctr/0004000000030000

# Only specific fields
GET /ctr/0004000000030000?fields=name,description,publisher,region

GET /ctr/:tid/meta/:meta

Retrieve a specific metadata field for a title.

Parameters

  • tid path required - 16-character hexadecimal Title ID
  • meta path required - Field name: name, formal_name, description, publisher, region, category, genres, languages, rating_system, smdh, release_date_on_eshop, …

Example Requests

GET /ctr/0004000000030000/meta/name
GET /ctr/0004000000030000/meta/publisher
GET /ctr/0004000000030000/meta/region
GET /ctr/0004000000030000/meta/smdh

Response

Returns the single metadata value (string, number, object, or array depending on the field).

📸 Screenshots

GET /ctr/:tid/screen/:num

Get a specific compiled screenshot (JPEG format).

Parameters

  • tid path required - 16-character hexadecimal Title ID
  • num path required - Screenshot number

Example Request

GET /ctr/0004000000030000/screen/1

Response

Returns raw JPEG image data with Content-Type: image/jpeg.

GET /ctr/:tid/screen_u

Get a list of all available uncompiled screenshots (upper and lower screens).

Response

{
  "count": {
    "upper": 3,
    "lower": 3,
    "total": 6
  },
  "screenshots": {
    "upper": [
      {"number": 1, "url": "{{BASE_URL}}/ctr/0004000000030000/screen_u/1/u"},
      {"number": 2, "url": "{{BASE_URL}}/ctr/0004000000030000/screen_u/2/u"}
    ],
    "lower": [
      {"number": 1, "url": "{{BASE_URL}}/ctr/0004000000030000/screen_u/1/l"},
      {"number": 2, "url": "{{BASE_URL}}/ctr/0004000000030000/screen_u/2/l"}
    ]
  }
}
GET /ctr/:tid/screen_u/:num/:screen

Get an uncompiled screenshot (upper or lower screen) (JPEG format).

Parameters

  • tid path required - 16-character hexadecimal Title ID
  • num path required - Screenshot number
  • screen path required - Screen type: u for upper, l for lower

Example Requests

GET /ctr/0004000000030000/screen_u/1/u  # Upper screen
GET /ctr/0004000000030000/screen_u/1/l  # Lower screen

Response

Returns raw JPEG image data with Content-Type: image/jpeg.

ℹ️ Information

📝 Important Notes

  • All Title IDs are automatically converted to uppercase
  • Endpoints can be called with or without a trailing slash
  • All images are served in JPEG format
  • Metadata is refreshed automatically (new / changed titles every 12 hours)
  • Regions use uppercase ISO / market codes (JP, US, EU, FREE, …)
  • Categories: base, digital-demos, kiosk-demos, region-free, unknown-other, dlc, dsiware, extras (+ nested extras/*), updates, videos, virtual-console, themes
  • Response fields include publisher, smdh, and category
  • Uncompiled screenshots are separated by upper (u) and lower (l) screens
  • API responses use standard HTTP status codes (200, 404, 500)
